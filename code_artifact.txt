1. ОБЩИЕ СВЕДЕНИЯ И СТРУКТУРА ПРОГРАММЫ
--------------------------------------------------------------------------------
- Исходный код программы располагается в файле `code.txt`.
- Инструкции верхнего уровня выполняются последовательно сверху вниз до конца
  файла (инструкция `HALT`).
- Каждая простая инструкция (присваивание, вызов функции как инструкция,
  объявление массива, `print`, `return`) обязана заканчиваться точкой с
  запятой `;`.
- Составные блоки кода (тела функций, ветки `if`/`else`, тело цикла `while`)
  всегда заключаются в фигурные скобки `{ ... }`.
- Объявления функций (`func`) могут находиться в любом месте файла — как до,
  так и после места их вызова (поддерживаются опережающие ссылки и взаимная
  рекурсия).


2. ТИПЫ ДАННЫХ И ЛИТЕРАЛЫ
--------------------------------------------------------------------------------
В языке используются три базовые сущности:

  1) Целые числа (32-битные знаковые, `int32_t`)
     - Основной тип для вычислений, индексов массивов и логических условий.
     - Логические значения представлены числами: `0` — ложь (false), любое
       ненулевое значение — истина (true). Операции сравнения и логики
       возвращают `1` или `0`.
     - Пример: `0`, `42`, `-15`.

  2) Одномерные массивы (`array`)
     - Динамически выделяются в куче (`heap`), индексация начинается с `0`.
     - Размер массива задаётся любым целочисленным выражением во время
       выполнения программы.

  3) Строковые литералы (`"..."`)
     - Используются исключительно в инструкции `print` для посимвольного
       вывода текста в стандартный поток вывода.
     - Пример: `print "Hello, world!";`


3. ПЕРЕМЕННЫЕ И ОБЛАСТИ ВИДИМОСТИ
--------------------------------------------------------------------------------
- Скалярные переменные не требуют предварительного объявления с указанием типа:
  переменная создаётся автоматически при первом присваивании (`=`).
- Составное присваивание (`+=`, `-=` и др.) и чтение требуют, чтобы переменная
  уже была объявлена ранее.

Правила областей видимости:
  1) Глобальная область:
     - Все переменные и массивы, созданные вне функций, являются глобальными.
     - Глобальные переменные доступны для чтения и изменения из любой функции.

  2) Локальная область (внутри `func`):
     - Параметры функции и локальные массивы всегда принадлежат кадру текущей
       функции и уничтожаются при выходе из неё (`RET`).
     - Если внутри функции выполняется присваивание `x = ...` и имя `x` не
       совпадает ни с одним параметром или локальной переменной этой функции,
       компилятор проверяет глобальную таблицу:
         * если глобальная скалярная переменная `x` существует — изменяется она;
         * если глобальной `x` нет — создаётся новая локальная переменная `x`.

  3) Перекрытие имён (Shadowing):
     - Параметр функции с именем `g` перекрывает глобальную переменную `g`:
       внутри функции все обращения к `g` работают только с локальным
       параметром, не затрагивая глобальную переменную.
     - Локальный массив `array a[...];`, объявленный внутри функции, перекрывает
       глобальный массив `a` на время выполнения этой функции.


4. МАССИВЫ
--------------------------------------------------------------------------------
Объявление массива:
  array <имя>[<выражение_размера>];

Примеры:
  array nums[10];
  n = 5;
  array dynamic_arr[n * 2];

Правила работы с массивами:
  - Повторное объявление массива с тем же именем в одной и той же области
    видимости запрещено (ошибка компиляции `Cannot redefine array!`).
  - Нельзя использовать имя массива как скаляр (`nums = 5;`) и обращаться по
    индексу к скалярной переменной (`x[0] = 1;`).
  - При обращении `arr[i]` виртуальная машина проверяет границы `0 <= i < len`.
    При выходе за пределы выбрасывается исключение времени выполнения.


5. ОПЕРАТОРЫ И ПРИОРИТЕТ ВЫЧИСЛЕНИЙ
--------------------------------------------------------------------------------
Операторы перечислены от высшего приоритета к низшему:

  Приоритет | Операторы                          | Описание
  ----------+------------------------------------+--------------------------------
      1     | ( ... )                            | Группировка выражений
            | id(arg1, arg2, ...)                | Вызов функции
            | arr[idx]                           | Доступ к элементу массива
            | input                              | Ввод целого числа из stdin
            | id++, id--, arr[idx]++, arr[idx]-- | Постфиксный инкремент/декремент
  ----------+------------------------------------+--------------------------------
      2     | !                                  | Логическое НЕ
            | ~                                  | Побитовое НЕ (инверсия бит)
            | ++id, --id, ++arr[idx], --arr[idx] | Префиксный инкремент/декремент
  ----------+------------------------------------+--------------------------------
      3     | *, /                               | Умножение, целочисленное деление
  ----------+------------------------------------+--------------------------------
      4     | +, -                               | Сложение, вычитание
  ----------+------------------------------------+--------------------------------
      5     | <, <=, >, >=, ==, !=               | Операции сравнения
  ----------+------------------------------------+--------------------------------
      6     | &                                  | Побитовое И
  ----------+------------------------------------+--------------------------------
      7     | ^                                  | Побитовое исключающее ИЛИ (XOR)
  ----------+------------------------------------+--------------------------------
      8     | |                                  | Побитовое ИЛИ
  ----------+------------------------------------+--------------------------------
      9     | &&                                 | Логическое И
  ----------+------------------------------------+--------------------------------
     10     | ||                                 | Логическое ИЛИ
  ----------+------------------------------------+--------------------------------
     11     | =                                  | Простое присваивание
            | +=, -=, *=, /=, &=, |=, ^=         | Составное присваивание

Примечания:
  - Присваивание является выражением и возвращает присвоенное значение
    (поддерживаются цепочки вида `a = b = 10;`).
  - Все арифметические операции (`+`, `-`, `*`, `/`) контролируют 32-битное
    знаковое переполнение и деление на ноль.


6. УПРАВЛЯЮЩИЕ КОНСТРУКЦИИ
--------------------------------------------------------------------------------
Условный оператор `if` / `else`:
  - Условие указывается в круглых скобках `( ... )`.
  - Фигурные скобки `{ ... }` обязательны как для ветки `if`, так и для `else`.
  - Ветка `else` является необязательной.

  Синтаксис:
    if (<условие>) {
        <инструкции>
    }
    else {
        <инструкции>
    }

Цикл с предусловием `while`:
  - Выполняется, пока выражение в скобках не равно `0`.
  - Фигурные скобки `{ ... }` обязательны.

  Синтаксис:
    while (<условие>) {
        <инструкции>
    }


7. ФУНКЦИИ
--------------------------------------------------------------------------------
Объявление функции:
  func <имя>(<параметр_1>, <параметр_2>, ...) {
      <инструкции>
  }

Параметры:
  - Скалярный параметр записывается просто именем: `x` (передаётся по значению).
  - Параметр-массив объявляется с ключевым словом `array`: `array arr`.
  - Массивы передаются в функцию по указателю на блок в куче: изменение
    элементов `arr[i] = ...` внутри функции изменяет исходный массив.
  - Имена параметров в пределах одной функции не могут повторяться.

Вызов функции:
  - Синтаксис: `<имя>(<арг_1>, <арг_2>, ...)`
  - Для параметра-массива при вызове передаётся только имя массива без скобок
    (например: `sort(my_arr, 10)`).
  - Количество и типы аргументов (скаляр или массив) строго проверяются при
    компиляции.
  - Функцию можно вызывать как часть выражения (`x = add(2, 3) * 4;`) или как
    отдельную инструкцию (`log_data(arr);`).

Возврат значения (`return`):
  - Синтаксис: `return <выражение>;`
  - После `return` всегда должно следовать выражение (например, `return 0;`).
  - Если выполнение доходит до закрывающей скобки `}` функции без явного
    `return`, функция автоматически возвращает `0`.


8. ВВОД И ВЫВОД
--------------------------------------------------------------------------------
Вывод (`print`):
  - Вывод числа (результата выражения):
      print <выражение>;
      Пример: `print a + b * 2;`
  - Вывод строкового литерала:
      print "<текст>";
      Пример: `print "Result: ";`
  - Примечание: `print` не добавляет перенос строки автоматически.

Ввод (`input`):
  - Ключевое слово `input` (без скобок) является выражением: при вычислении оно
    считывает одно 32-битное целое число со стандартного потока ввода (`stdin`)
    и возвращает его значение.
  - Примеры использования:
      n = input;
      arr[i] = input;
      res = sum(input, input);
      if (input > 0) { print "OK"; }
  - При некорректном вводе (не число, лишние символы в строке, выход за пределы
    `int32_t`) виртуальная машина выводит сообщение `Error input! Try again!` и
    повторно запрашивает ввод. При достижении конца потока (`EOF`) выбрасывается
    исключение `Unexpected end of input!`.


9. ТИПИЧНЫЕ ОШИБКИ КОМПИЛЯЦИИ И ВЫПОЛНЕНИЯ
--------------------------------------------------------------------------------
Ошибки этапа компиляции (Parser / Assembler):
  - `Undeclared variable!` — обращение к необъявленной переменной.
  - `Undeclared function!` — вызов несуществующей функции.
  - `Invalid variable type!` — несоответствие типа (передача скаляра вместо
    массива или наоборот, индексация скаляра, присваивание массиву без индекса).
  - `Cannot redefine array!` — повторное объявление массива в той же области.
  - `Redefine function!` / `Redefine function parameter!` — дублирование имени
    функции или параметра.
  - `Expected ;` / `{` / `}` / `(` / `)` / `[` / `]` / `,` — нарушение
    синтаксиса.

Ошибки времени выполнения (Virtual Machine):
  - `Division by zero!` — деление на ноль.
  - `Overflow on ADD! / SUB! / MUL! / DIV!` — переполнение 32-битного целого.
  - `Array index out of bounds...` — выход индекса за пределы `[0, size - 1]`.
  - `Invalid array size on ALLOC!` — отрицательный или слишком большой размер
    массива (`< 0` или `> 10 000 000`).
  - `Call stack overflow!` — превышение максимальной глубины рекурсии (`10000`).
  - `Unexpected end of input!` — закрытие входного потока (`EOF`) при `input`.


10. ПОЛНЫЙ ПРИМЕР ПРОГРАММЫ
--------------------------------------------------------------------------------
// Чтение размера и элементов массива, разворот массива и подсчёт суммы

n = input;
array data[n];

i = 0;
while (i < n) {
    data[i] = input;
    i++;
}

reverse(data, 0, n - 1);
total = sum_array(data, n);

print "Sum: ";
print total;
print " First: ";
print data[0];

func reverse(array arr, left, right) {
    if (left >= right) {
        return 0;
    }
    tmp = arr[left];
    arr[left] = arr[right];
    arr[right] = tmp;
    return reverse(arr, left + 1, right - 1);
}

func sum_array(array arr, len) {
    acc = 0;
    idx = 0;
    while (idx < len) {
        acc += arr[idx];
        idx++;
    }
    return acc;
}
