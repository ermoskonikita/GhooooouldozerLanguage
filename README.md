# Virtual Machine & Interpreter (C++)

Собственная стековая виртуальная машина (VM), компилятор/транслятор и набор инструментов для исполнения пользовательского байт-кода, написанные на современном C++ (C++17/20).

## Архитектура проекта

Проект реализует полный цикл обработки исходного кода — от лексического анализа до исполнения инструкций в виртуальной машине:

1. **Лексический анализ (`Lexer.h`, `Lexer.cpp`, `Token.h`)** — разбиение исходного кода из файла (`code.txt`) на последовательность токенов.

2. **Синтаксический анализ (`Parser.h`, `Parser.cpp`)** — разбор токенов и построение синтаксических конструкций.

3. **Ассемблер (`Assembler.h`, `Assembler.cpp`, `OpCode.h`)** — генерация компактного бинарного байт-кода с 32-битными операндами (`little-endian`).

4. **Виртуальная машина (`Virtual_Machine.h`, `Virtual_Machine.cpp`)** — стековый интерпретатор байт-кода с поддержкой переменных, вызовов функций и динамической памяти.

## Возможности виртуальной машины

* **Модель памяти:**

  * **Стек операндов (`stack`)** — для вычислений и передачи аргументов.

  * **Массив переменных (`variables`)** — 1024 ячейки для хранения локальных/глобальных значений и указателей на массивы.

  * **Куча (`heap`)** — динамическое выделение памяти под одномерные массивы (`ALLOC`) с хранением длины блока и автоматической проверкой границ при чтении/записи (`LOAD_INDEX`, `STORE_INDEX`).

  * **Стек вызовов (`call_stack`)** — поддержка функций и рекурсии (`CALL`, `RET`) с защитой от переполнения глубины вызовов.

* **Безопасность и обработка ошибок:**

  * Строгий контроль переполнения (overflow) и исчерпания (underflow) стека данных и стека вызовов.

  * Защита от целочисленного переполнения 32-битной арифметики (`ADD`, `SUB`, `MUL`, `DIV`) и деления на ноль.

  * Валидация адресов переходов (`JMP`, `JZ`, `JNZ`, `CALL`) и границ массива/переменных с информативными исключениями `std::runtime_error`.

## Набор инструкций (OpCodes)

| Категория | Инструкции | Описание | 
| ----- | ----- | ----- | 
| **Стек** | `PUSH`, `POP`, `DUP`, `SWAP`, `SWAP3` | Управление элементами на вершине стека | 
| **Арифметика** | `ADD`, `SUB`, `MUL`, `DIV` | Знаковая 32-битная арифметика с проверкой переполнения | 
| **Битовые операции** | `BAND`, `BOR`, `BXOR`, `BNOT` | Побитовые И, ИЛИ, исключающее ИЛИ, НЕ | 
| **Сравнение и логика** | `LT`, `LE`, `GT`, `GE`, `EQ`, `NE`, `AND`, `OR`, `NOT` | Логические операции и операции отношения | 
| **Память и массивы** | `LOAD`, `STORE`, `ALLOC`, `LOAD_INDEX`, `STORE_INDEX` | Работа с переменными и динамическими массивами в куче | 
| **Управление потоком** | `JMP`, `JZ`, `JNZ`, `CALL`, `RET`, `HALT` | Безусловные/условные переходы, вызов функций и остановка ВМ | 
| **Ввод/Вывод** | `PRINT`, `PRINT_CHAR` | Вывод чисел и ASCII-символов в стандартный поток | 

## Сборка и запуск

Проект поддерживает сборку через **CMake** (совместим с MSVC / Visual Studio, GCC / MinGW и Clang).

### Требования

* Компилятор с поддержкой **C++17** или новее

* **CMake** версии `3.16` или выше

### Инструкция по сборке

# 1. Клонирование репозитория
```bash
git clone https://github.com/ermoskonikita/GhooooouldozerLanguage.git

cd GhooooouldozerLanguage


# 2. Конфигурация и сборка
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 3. Запуск (файл code.txt автоматически копируется в директорию сборки)
cd build
./VirtualMachine   # На Windows: .\Release\VirtualMachine.exe или .\VirtualMachine.exe

```

## Использование

Поместите исходный код вашей программы в файл `code.txt` в корневой директории проекта и запустите исполняемый файл. В случае синтаксической ошибки или ошибки времени выполнения (например, выход за границы массива или деление на ноль) виртуальная машина безопасно остановится и выведет описание исключения.
