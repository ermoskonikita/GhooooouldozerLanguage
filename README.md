# Virtual Machine & Interpreter (C++)

Собственная стековая виртуальная машина (VM), компилятор/транслятор и набор инструментов для исполнения пользовательского байт-кода, написанные на современном C++ (C++17/20).

## Архитектура проекта

Проект реализует полный цикл обработки исходного кода — от лексического анализа до исполнения инструкций в виртуальной машине:

1. **Лексический анализ (`Lexer.h`, `Lexer.cpp`, `Token.h`)** — разбиение исходного кода из файла (`code.txt`) на последовательность токенов.

2. **Синтаксический анализ (`Parser.h`, `Parser.cpp`)** — двухпроходный разбор токенов:
   - предварительное индексирование сигнатур функций (`collectFunctions`) для поддержки вызовов до объявления (forward references) и контроля типов аргументов;
   - генерация инструкций с разделением глобальной и локальной областей видимости (включая перекрытие имён — shadowing).

3. **Ассемблер (`Assembler.h`, `Assembler.cpp`, `OpCode.h`)** — двухпроходная генерация компактного бинарного байт-кода с разрешением меток переходов и функций и кодированием 32-битных операндов (`little-endian`).

4. **Виртуальная машина (`Virtual_Machine.h`, `Virtual_Machine.cpp`)** — стековый интерпретатор байт-кода с поддержкой глобальной и кадровой локальной памяти, вызовов функций, рекурсии и динамических массивов.

## Возможности языка и виртуальной машины

- **Функции и области видимости:**
  - Поддержка пользовательских функций (`func`), вложенных, рекурсивных и взаимно-рекурсивных вызовов, а также неявного возврата `0` при отсутствии `return`.
  - Статическая проверка количества и типов передаваемых аргументов (скаляры и массивы) на этапе компиляции.
  - Передача массивов в функции по указателю в куче (изменение элементов внутри функции модифицирует исходный массив).
  - Изолированные локальные переменные и параметры внутри функций с возможностью перекрытия (shadowing) глобальных переменных и массивов.

- **Модель памяти:**
  - **Стек операндов (`stack`)** — для вычисления выражений, передачи аргументов при вызове и возврата результатов функций.
  - **Глобальная память (`variables`)** — 1024 ячейки для хранения глобальных скалярных переменных и указателей на глобальные массивы.
  - **Стек локальных переменных (`locals_stack`) и указатель кадра (`fp`)** — непрерывный стек локальных кадров функций: инструкция `ENTER` резервирует слоты под параметры и локальные переменные при входе в функцию, а `RET` автоматически освобождает кадр при выходе.
  - **Куча (`heap`)** — динамическое выделение памяти под одномерные массивы (`ALLOC`, `ALLOC_LOCAL`) с хранением длины блока и автоматической проверкой границ при чтении и записи (`LOAD_INDEX`, `STORE_INDEX`, `LOAD_LOCAL_INDEX`, `STORE_LOCAL_INDEX`).
  - **Стек вызовов (`call_stack`)** — хранение кадров возврата (`return_ip`, `prev_fp`) для корректного восстановления потока выполнения и базового адреса локальных переменных после завершения функции.

- **Безопасность и обработка ошибок:**
  - Строгий контроль переполнения (overflow) и исчерпания (underflow) стека операндов, локального стека и стека вызовов.
  - Защита от целочисленного переполнения 32-битной знаковой арифметики (`ADD`, `SUB`, `MUL`, `DIV`) и деления на ноль.
  - Валидация адресов переходов (`JMP`, `JZ`, `JNZ`, `CALL`), границ массивов в куче и индексов локальных/глобальных переменных с выбросом информативных исключений `std::runtime_error`.

## Набор инструкций (OpCodes)

| Категория | Инструкции | Описание |
| ----- | ----- | ----- |
| **Стек** | `PUSH`, `POP`, `DUP`, `SWAP`, `SWAP3` | Управление элементами на вершине стека операндов |
| **Арифметика** | `ADD`, `SUB`, `MUL`, `DIV` | Знаковая 32-битная арифметика с проверкой переполнения |
| **Битовые операции** | `BAND`, `BOR`, `BXOR`, `BNOT` | Побитовые И, ИЛИ, исключающее ИЛИ, НЕ |
| **Сравнение и логика** | `LT`, `LE`, `GT`, `GE`, `EQ`, `NE`, `AND`, `OR`, `NOT` | Логические операции и операции отношения |
| **Глобальная память и куча** | `LOAD`, `STORE`, `ALLOC`, `LOAD_INDEX`, `STORE_INDEX` | Работа с глобальными переменными и динамическими массивами |
| **Локальная память (функции)** | `ENTER`, `LOAD_LOCAL`, `STORE_LOCAL`, `ALLOC_LOCAL`, `LOAD_LOCAL_INDEX`, `STORE_LOCAL_INDEX` | Выделение кадра функции и работа с локальными переменными и массивами |
| **Управление потоком** | `JMP`, `JZ`, `JNZ`, `CALL`, `RET`, `HALT` | Безусловные/условные переходы, вызов/возврат из функций и остановка ВМ |
| **Ввод/Вывод** | `PRINT`, `PRINT_CHAR` | Вывод чисел и ASCII-символов в стандартный поток |

## Сборка и запуск

Проект поддерживает сборку через **CMake** (совместим с MSVC / Visual Studio, GCC / MinGW и Clang).

### Требования

- Компилятор с поддержкой **C++17** или новее
- **CMake** версии `3.16` или выше

### Инструкция по сборке

```bash
# 1. Клонирование репозитория
git clone [https://github.com/ermoskonikita/GhooooouldozerLanguage.git](https://github.com/ermoskonikita/GhooooouldozerLanguage.git)
cd GhooooouldozerLanguage

# 2. Конфигурация и сборка
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 3. Запуск (файл code.txt автоматически копируется в директорию сборки)
cd build
./VirtualMachine   # На Windows: .\Release\VirtualMachine.exe или .\VirtualMachine.exe
```

## Использование

Поместите исходный код программы в файл `code.txt` в корневой директории проекта и запустите исполняемый файл. В случае синтаксической ошибки или ошибки времени выполнения (например, несовпадение типов аргументов, выход за границы массива или деление на ноль) виртуальная машина безопасно остановится и выведет описание исключения.

### Пример программы (`code.txt`)

```text
array nums[3];
nums[0] = 10;
nums[1] = 20;
nums[2] = 30;

print process(nums, 3, 4);

func fact(n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}

func process(array arr, len, k) {
    sum = fact(k);
    i = 0;
    while (i < len) {
        arr[i] += 1;
        sum += arr[i];
        i++;
    }
    return sum;
}
```
